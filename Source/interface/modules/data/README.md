# Data management

This package manages the representation and editing of existing fuzzy color space definitions in the application.

| File | Responsibility |
| --- | --- |
| `DataManager.py` | Data tab, category and prototype tables, tree rendering, editing drafts, reference validation, and preparation of modified models. |
| `GranuleManager.py` | Granule selection and editing, inline creation tree, hierarchy/group and reference helpers used in creation and editing workflows. |
